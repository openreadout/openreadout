# openreadout-tdms

Reader for National Instruments TDMS files (`.tdms`), as LabVIEW, DAQmx logging and SignalExpress write them. This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/formats/ni-tdms.html>. Licensed MIT OR Apache-2.0.
