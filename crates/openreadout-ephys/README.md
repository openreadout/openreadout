# openreadout-ephys

Readers for electrophysiology recorders that have no crate of their own, such as HEKA PatchMaster, CED Spike2, Open Ephys and WinWCP. This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/formats/index.html>. Licensed MIT OR Apache-2.0.
