# Maintaining `openreadout-nd2`

Nikon ND2 (`nd2`): chunk-based files (NIS-Elements 3.x–5.x, format versions 2.x and 3.0) and legacy JPEG 2000-based files (NIS-Elements 2.x). Project-wide process: [docs/maintaining.md](../../docs/maintaining.md). Layout and vocabulary: [docs/formats/nd2.md](../../docs/formats/nd2.md); provenance: [docs/provenance/nd2.md](../../docs/provenance/nd2.md). **Clean room**: the `nd2` package (BSD-3) is read as documentation.

## Decode pipeline

1. **Detect** (`lib.rs` `Nd2Reader::sniff`): the chunk magic `0x0ABECEDA` followed by the file signature (`FILE_SIGNATURE`), or the JPEG 2000 signature box of a legacy `.nd2` (`LEGACY_SIGNATURE`). **The generation is the first branch** (`dataset.rs` `open_chunked` vs `open_legacy`, `Backend`).
2. **Chunked container** (`container.rs` `Nd2File::open`): the chunk map located from the file's last 8 bytes (`parse_map`), or rebuilt by scanning when damaged (`rescue_scan`; the rescue is reported as undecoded structure in assurance).
3. **Metadata** (`lv.rs`, `variant.rs`, `meta.rs`): **format versions branch here**: version 3.0 stores metadata as LV typed key-value chunks (`lv_decode`: `ImageAttributesLV!`, `ImageMetadataLV!`, `ImageMetadataSeqLV|0!`, `ImageCalibrationLV|0!`, `ImageTextInfoLV!`); version 2.x as XML "variant" documents in chunks without the `LV` suffix (`variant_decode`). Both decode to the same JSON shape, so `meta.rs` normalizes once: attributes (`Attributes`), the experiment loop tree (`loops_from_lv`: time, XY position, Z stack, NE-time with valid periods, spectral loops), frame layout (`FrameLayout`, outermost loop slowest), picture planes/channels (`planes_from_lv`: wavelengths probe → filter, colours, camera settings), events, ROIs, dates (Julian day, text dates).
4. **Per-frame records** (`frames.rs`): the custom-data tag table (`CustomDataVar|CustomDataV2_0!`) and the arrays it describes (`CustomData|<tag>!`: stage X/Y/Z, acquisition times).
5. **Pixels** (`dataset.rs` `read_plane_chunked`): `ImageDataSeq|N!` chunks: an 8-byte timestamp, then the frame, uncompressed or zlib (`eCompression` 0), rows padded to `uiWidthBytes`; channels de-interleaved (`deinterleave.rs`); RGB stored B, G, R is returned R, G, B.
6. **Legacy** (`legacy.rs`): a JPEG 2000 box sequence indexed by a box map at the end (`LABORATORY IMAGING ND BOX MAP 00`), XML metadata boxes (`legacy_xml_decode`) and one `jp2c` codestream per channel per frame, decoded by `dicom-toolkit-jpeg2000` (`read_plane_legacy`).

## Invariants and checks

- `check` (chunked): signature chunk and version string; chunk map from the trailing offset (or rebuilt); every mapped chunk has a valid header with the same name at its offset; every frame declared by `uiSequenceCount` exists with a full frame; the loop tree's frame count equals `uiSequenceCount`.
- `check` (legacy): JPEG 2000 signature and the box map (or a box walk); every box of the recorded type inside the file; every XML box parses; one codestream per picture plane per frame, each starting with SOC+SIZ and declaring the image size; loop-tree frames equal the per-frame metadata boxes.
- Refused (exit 6): lossy-compressed frames (`eCompression` 1: no public sample to derive the codec from).

## Debugging a new file

- `openreadout info FILE --view structure` lists every chunk (name, offset, size) or legacy box; `info --view full --json` → `vendor` has the decoded LV/variant trees under the chunk names; `info --view full --max-frames -1` the per-frame records.
- A new NIS-Elements version usually adds LV keys or a loop kind: `meta.rs` unit tests (`loop_tree_masks_and_merging`, `ne_time_periods_respect_validity`, `layout_handles_extra_and_missing_frames`, `wavelengths_follow_probe_then_filter`) are the templates; `lv.rs` tests pin the encoding.
- Oracles: the `nd2` package (primary), Bio-Formats (second opinion, black box).

## Fragile spots

- Loop tree: custom and unrecognised loop types fold into T; NE-time sub-loops are not expanded; `uiRepeatCount` is reported, not multiplied.
- Channel wavelengths follow the probe-then-filter rule of the `nd2` package; RGB planes carry none.
- Dates: `dTimeAbsolute` is a Julian day in UTC with a plausibility window (some files hold uninitialised values).
- ROI geometry is normalized from the documented tree layout; no corpus file contains ROIs.
