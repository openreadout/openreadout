# openreadout-agilent-ms

Reader for Agilent MassHunter `.d` mass-spectrometry directories. This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/formats/agilent-masshunter.html>. Licensed MIT OR Apache-2.0.
