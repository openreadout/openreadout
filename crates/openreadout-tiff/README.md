# openreadout-tiff

Reader for the TIFF family, including OME-TIFF, ImageJ, whole-slide formats such as Aperio SVS and Hamamatsu NDPI, and MetaMorph series. This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/formats/tiff.html>. Licensed MIT OR Apache-2.0.
