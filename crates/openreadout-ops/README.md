# openreadout-ops

Command-level operations shared by the OpenReadout CLI, MCP server and WebAssembly build: comparing two files (`compare`), the plain-English explanation of a file (`info --view explain`), extracting an embedded attachment (`export --attachment`) and projecting JSON output by pointer (`--only`). This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server.
