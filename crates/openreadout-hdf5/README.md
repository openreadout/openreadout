# openreadout-hdf5

Pure-Rust readers for HDF5-based formats: Imaris IMS, NWB 2.x and a generic HDF5 listing. This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/formats/hdf5.html>. Licensed MIT OR Apache-2.0.
