# openreadout-abf

Reader for Axon Binary Format (ABF 1 and ABF 2) patch-clamp recordings and Axon Text Files. This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/formats/abf.html>. Licensed MIT OR Apache-2.0.
