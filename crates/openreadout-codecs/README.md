# openreadout-codecs

Pure-Rust decoders (zstd, JPEG, JPEG 2000, LZW, deflate and others) used by the OpenReadout format readers. This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/>. Licensed MIT OR Apache-2.0.
