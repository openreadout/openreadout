# openreadout-signal

Signal processing for instrument data: NMR processing and peak picking, and electrophysiology feature and spike analysis. This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/recipes.html>. Licensed MIT OR Apache-2.0.
