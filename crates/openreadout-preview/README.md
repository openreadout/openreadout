# openreadout-preview

PNG and JPEG previews of OpenReadout datasets: image planes, channel composites, projections, trace sparklines and plate heat maps. This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/reference/commands/preview.html>. Licensed MIT OR Apache-2.0.
