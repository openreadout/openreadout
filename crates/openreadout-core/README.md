# openreadout-core

The shared traits, normalized metadata model, provenance tags, JSON output types, error codes and byte sources of OpenReadout. This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://github.com/openreadout/openreadout/blob/main/docs/architecture.md>. Licensed MIT OR Apache-2.0.
