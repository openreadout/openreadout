# openreadout-batch

Turns measurements from many instrument files into one table, joins sample sheets and plate layouts, and summarizes groups. This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/guides/batch.html>. Licensed MIT OR Apache-2.0.
