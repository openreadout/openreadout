# openreadout-diffraction

Readers for area-detector diffraction images: CBF/imgCIF (including the miniCBF files of PILATUS and EIGER detectors) and SMV (ADSC-style `.img`, also written for electron diffraction). This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/formats/diffraction.html>. Licensed MIT OR Apache-2.0.
