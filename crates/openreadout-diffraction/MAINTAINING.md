# Maintaining `openreadout-diffraction`

Area-detector diffraction images: CBF / imgCIF (`cbf`, `cbf.rs`) and SMV `.img` (`smv`, `smv.rs`), with shared helpers in `common.rs` (plain or gzip input, bounded reads, numbers, MD5 and base64). Both fill the geometry type of `openreadout_core::diffraction`, which the experiment, the preview (log contrast, masks, resolution rings) and the viewer use; NeXus NXmx lives in `openreadout-hdf5`. Start with [docs/maintaining.md](../../docs/maintaining.md) for the project-wide process. Notes: [docs/formats/cbf.md](../../docs/formats/cbf.md), [docs/formats/smv.md](../../docs/formats/smv.md).

## Decode pipeline

- **CBF** (`cbf.rs`): `CbfLayout::read` reads up to 4 MiB of text before the first `--CIF-BINARY-FORMAT-SECTION--`, tokenises it (`tokenize`: words, quotes, `;` text fields, `loop_`), then each section's MIME header (`read_section`) and jumps over its data to the next marker (`next_marker`). **Conversions branch here**: byte offset or none; others exit 6. `PilatusHeader::parse` reads the `# key value` lines of `_array_data.header_contents`; full imgCIF gives only the wavelength. `decode` turns the byte-offset stream into samples, checking each value against the element type.
- **SMV** (`smv.rs`): `SmvHeader::parse` reads `{ KEY=value; }` up to `HEADER_BYTES`; `TYPE` and `BYTE_ORDER` set the samples. **The beam-centre convention branches on `BEAMLINE`** (`beam_center_in_pixels`: TimePix_SU in pixels, else ADSC millimetres with X slow).

## Invariants and checks

- CBF: a binary section exists; dimensions hold the element count; byte-offset values need at least one byte each; data lie inside the file; `check` verifies `Content-MD5`, decodes every section and counts masked and overloaded pixels. A damaged stream is a corrupt-file error (exit 4); packed and canonical compression exit 6.
- SMV: `HEADER_BYTES` 512 B–1 MiB, `DIM=2`, positive sizes, a known `TYPE`, no compression; the file holds header and image (`truncated`, `trailing_bytes`); geometry values positive; the beam centre inside the image.

## Debugging a new file

- `openreadout info FILE --view full --json`: `vendor.header` (SMV keys, the PILATUS lines), `vendor.items` and `vendor.loops` (CIF), `vendor.sections` (MIME headers); `images[0].extra.diffraction` is what the preview and experiment use.
- `openreadout preview FILE`: the rings must be centred on the direct beam (or the beamstop shadow); if not, the beam-centre convention is wrong for this writer.
- `tests/synthetic.rs` builds CBF and SMV files; the unit tests in `cbf.rs` cover the byte-offset escapes and the PILATUS header. Oracle: FabIO in `oracle/diffraction.py`.

## Fragile spots

- SMV beam centres: writers disagree on units and axes; the rule follows dxtbx (TimePix_SU pixels, else ADSC mm with the axes swapped). A new detector that writes pixels needs its `BEAMLINE` added. Ceta-D headers carry a nominal centre.
- CBF: the PILATUS `Beam_xy` is (fast, slow) by dxtbx's reading; full imgCIF axis geometry is not turned into a beam centre; negative values are masks only on PILATUS and EIGER headers.
- One file is one image: sweeps are many files, read with `batch`.
