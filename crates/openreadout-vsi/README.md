# openreadout-vsi

Reader for Olympus/Evident cellSens VSI files and their `.ets` tile stores. This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/formats/vsi.html>. Licensed MIT OR Apache-2.0.
