# openreadout-index

The catalog behind `openreadout index` and `openreadout search`: a headers-only, resumable index of a lab file share, stored as Parquet. This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/guides/lab-shares.html>. Licensed MIT OR Apache-2.0.
