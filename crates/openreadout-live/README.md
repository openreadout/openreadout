# openreadout-live

Support for files that are still being written: a polling directory watcher with per-plane and per-scan events, and live QC rules. This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/guides/lab-shares.html>. Licensed MIT OR Apache-2.0.
