# openreadout-plexon

Reader for Plexon PLX and PL2 electrophysiology files. This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/formats/plexon.html>. Licensed MIT OR Apache-2.0.
