# openreadout-assay

Plate-reader assay analysis: plate layouts, blank subtraction, standard curves, dose-response fits, kinetics and assay quality. This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/guides/plate-analysis.html>. Licensed MIT OR Apache-2.0.
