# openreadout-mzml-writer

Writes the spectra of an OpenReadout dataset as indexed mzML and reads the file back to verify it. This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/reference/commands/export.html>. Licensed MIT OR Apache-2.0.
