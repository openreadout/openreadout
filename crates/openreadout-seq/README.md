# openreadout-seq

Readers for DNA sequencer output: Illumina run folders (RunInfo.xml, RunParameters.xml, InterOp metrics, BCL and CBCL base calls), Oxford Nanopore POD5 and FAST5 raw signal, and FASTQ and BAM read files. This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/formats/sequencing.html>. Licensed MIT OR Apache-2.0.
