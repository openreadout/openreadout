# Maintaining `openreadout-qpcr`

Real-time PCR run files: RDML 1.0–1.4 (`rdml`, read and written), Applied Biosystems / Thermo Fisher `.eds` (`applied-biosystems-eds`: QuantStudio, ViiA 7, StepOne, 7500, Design & Analysis 2), Qiagen Rotor-Gene `.rex` (`rotor-gene-rex`), Roche LightCycler 480 `.ixo` (`roche-lightcycler-ixo`) and LightCycler 96 `.lc96p`; Bio-Rad CFX `.pcrd` (`bio-rad-pcrd`) is detected and refused (encrypted: clean-room rule 4). Project-wide process: [docs/maintaining.md](../../docs/maintaining.md). Notes: [docs/formats/qpcr.md](../../docs/formats/qpcr.md); provenance: [docs/provenance/qpcr.md](../../docs/provenance/qpcr.md).

## Decode pipeline

1. **Detect** (`lib.rs`, one reader per format): zip containers recognised by their members (`first_member`: `rdml_data.xml`, `apldbio/sds/…`, the 7500/StepOne members, the JSON layout), `.pcrd` by its encrypted member (`first_member_encrypted`, exit 6), `.rex` and `.ixo` by their XML roots (`<Experiment><RexHeader>`, `<objectstream signature="IXOS">`). Zips go through `openreadout_core::zip` (member names case-insensitive, `\` read as `/`).
2. **Dialects** — **every vendor and software generation branches here**, each parsing into the same model (`model.rs` `QpcrData`: samples, targets, dyes, thermal programs, runs of reactions with one assay per target, curves, melts, vendor results):
   - RDML (`rdml.rs` `parse_rdml`): 1.0 ids and formats (`v10_format`) through 1.4.
   - `.eds` (`eds.rs` `parse_eds`): the `apldbio/sds/` XML layout, the 7500/StepOne layout (`multicomponent_data.txt`) and the JSON layout (Design & Analysis 2); plate setup, thermal protocol, multicomponent signals, the vendor's results and baseline windows (`automatic_baseline_windows`, `estimate_thresholds`).
   - `.rex` (`rex.rs`): samples by tube, groups, raw channel readings, thermal profile; no analysis results stored.
   - `.ixo` (`ixo.rs`): an XML object stream with an embedded base64+zlib object stream of readings; the vendor's Cp and calls.
   - `.lc96p` (`lc96.rs`): an RDML 1.1 zip plus Roche members with the vendor's analysis attached to reactions.
3. **Dataset** (`dataset.rs` `QpcrDataset`): table 0 `results` (well × target), tables 1–2 `amplification` and `melt` curves, traces per run and dye.
4. **Analysis** (`analysis.rs`, `report.rs`): our own threshold Cq (linear baseline), melt −dF/dT, ΔΔCq and standard curves, reported next to the vendor's values, never over them. `rdml_write.rs` writes RDML 1.3 (verified by read-back).

## Invariants and checks

- `check`: zip central directory and every member's CRC-32; setup, results and curves parse; curve lengths match the cycle count.

## Debugging a new file

- `openreadout info FILE --view structure` lists the zip members (or XML objects); `info --view full --json` → `vendor` has the setup and results trees; `openreadout analyze qpcr FILE --cq` compares our Cq with the vendor's for every well — a systematic difference points at the baseline or threshold reading.
- `tests/synthetic.rs` builds `.eds` (all three layouts), RDML, `.rex` and `.ixo` files; the dialect modules hold unit tests of their parsers (`text_results`, `multicomponent_txt_records`, `small_rex`, `small_ixo`).
- Oracles: `oracle/qpcr.py` (the vendor's own text exports as `oracle-export`, RDML via rdmlpython) and the `qpcr_*` corpus tests.

## Fragile spots

- `.eds` has three layouts; the XML one differs between QuantStudio and ViiA 7 software versions (well geometry, instrument names; `instruments_and_geometry`).
- Automatic baseline windows are recovered from the data when the file does not store them, or refused (`automatic_baseline_window_is_recovered_or_refused`).
- `.lc96p` and `.ixo` are validated on few files (2026-09-26 provenance entries); `.pcrd` stays refused.
- LightCycler 96: the RDML `cq` under a call other than Positive is withheld (`cq_stored`), even when plausible; other RDML readers (rdmlpython) report it, so the corpus test counts the withheld values per file against `LC96_WITHHELD` (`tests/qpcr_oracle/mod.rs`). A new LightCycler 96 file needs its count adjudicated there.
