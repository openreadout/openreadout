# Maintaining `openreadout-wsi`

Whole-slide formats that keep their pyramid as many small stored images next to a settings file: 3DHISTECH MIRAX (`mirax`, module `src/mirax/`). Project-wide process: [docs/maintaining.md](../../docs/maintaining.md). Layout: [docs/formats/mirax.md](../../docs/formats/mirax.md); provenance: [docs/provenance/mirax.md](../../docs/provenance/mirax.md) (no specification: OpenSlide's public format documentation and the corpus files; placement derived by comparison with OpenSlide, run as a black box).

## Decode pipeline

1. **Detect** (`mirax/mod.rs` `sniff_input`): extension `.mrxs` (the file is a JPEG preview) and the data directory of the same name (`slide.rs` `data_dir`).
2. **Settings** (`ini.rs` `Ini::parse`, `decode_text`): `Slidedat.ini`, UTF-8 with a BOM (UTF-16LE with a BOM accepted).
3. **Index** (`index.rs` `IndexFile`): version, slide id, root tables, linked data-page lists (`hier_items`, `nonhier_items`); loops and out-of-file pointers are errors.
4. **Slide model** (`slide.rs` `MiraxSlide::open`): pyramid levels (`ZoomLevel`, grid `step` from the cumulative `IMAGE_CONCAT_FACTOR`), filters, non-hierarchical records, camera positions (`read_cameras`: raw position buffer, or the zlib table of version 2.2+). **Slide versions and saved (downsampled) slides branch here.**
5. **Placement** (`render.rs` `LevelLayout::build`): every stored image, or every camera photo inside an image ("subtile") at coarse levels, at its camera's position / 2^level; spatial buckets for region queries.
6. **Composition** (`render.rs` `compose`): bilinear resampling at fractional offsets, two-stage for fractional source rectangles, "saturate" painting in reverse raster order, fill colour behind. `dataset.rs` `read_level_region` composes in bands, decoding the needed images in parallel (`image.rs` `decode_rgb`: JPEG, PNG, BMP) into a 256 MiB cache; fluorescence channels are picked from the composed RGB (component 2 − storing channel).

## Invariants and checks

- At level 0 every offset is an integer: the stored samples are copied unchanged (`tests/mirax_synthetic.rs` `level0_copies_samples_and_the_later_photo_wins`).
- A region equals the crop of the whole level (same test file, `coarser_levels_resample_fractional_positions`); bands compose independently.
- Level-0 size is OpenSlide's (`level0_size`); level k = level 0 / 2^k rounded down.
- `check`: index lists, data files present and named for the slide, every image and record inside its data file, images on their level's grid, camera positions for stored images, image headers of the level's size, the first image of each level decodes.

## Debugging a new file

- `openreadout info SLIDE.mrxs --json` → `images[0].extra.mirax` shows the grid, divisions, camera table source, levels (step, concat factor, format, image size, count); `dump` → `vendor.slidedat` has every setting.
- Compare regions with OpenSlide: `oracle/gen_regions.py` (`mirax_targets`) and the corpus test `regions`; the session scripts that derived the placement model are summarised in the provenance log. Differences of 1–4 grey levels are JPEG decoding and OpenSlide's 8-bit compositing; a misplaced photo shows as tens of levels along a seam.
- A new `IMAGE_FORMAT`, more than three fluorescence filters, a grid not divisible by the camera divisions or an image/photo size mismatch exit 6 or 4 with the reason.
- The synthetic fixture is written by `oracle/make_mirax_fixtures.py`; extend it rather than hand-editing bytes.

## Fragile spots

- Composition reproduces OpenSlide's rendering, including its double resampling of fractional subtiles: a different but equally valid resampling would disagree by up to ~30 levels at coarse levels. Keep `render.rs` in step with the provenance notes.
- `IMAGE_FILL_COLOR_BGR` byte order is unverified (grey in every corpus file); a non-grey value is noted and reported as assumed.
- Slides without camera positions (exported) have their metadata read but their pixels refused (exit 6, `LevelLayout::build`): no development file confirms grid placement.
- `level0_size` uses `round(OVERLAP_X) / step₀`, OpenSlide's convention matched on three kinds of slide; a new kind of saved slide may differ.
