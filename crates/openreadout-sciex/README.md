# openreadout-sciex

Reader for legacy Sciex `.wiff` files with their `.wiff.scan` companions. This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/formats/sciex-wiff.html>. Licensed MIT OR Apache-2.0.
