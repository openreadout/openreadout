# Maintaining `openreadout-biophys`

Biophysics bench instruments, one module per format: MicroCal ITC (`microcal-itc`, `itc.rs`), Cytiva Biacore `.blr` (`cytiva-biacore-blr`, `biacore.rs`), Agilent Seahorse XF `.asyr` (`agilent-seahorse-asyr`, `seahorse.rs`), GenePix Results `.gpr` (`genepix-gpr`, `gpr.rs`). Project-wide process: [docs/maintaining.md](../../docs/maintaining.md). Notes and provenance: `docs/formats/{microcal-itc,cytiva-biacore,agilent-seahorse,genepix-gpr}.md` and the provenance logs of the same names.

## Decode pipeline

Each module is a self-contained parser plus its `Dataset`; `lib.rs` holds the four readers.

- **ITC** (`itc.rs`): a text header (method, concentrations, cell volume, instrument; `parse`, `model`) and the thermogram, one block per injection (`rows`, `regular_time`). The thermogram is a trace (differential power, cell temperature against time), injections a table. **Variants**: VP-ITC versus iTC200 header lines (`model`).
- **Biacore** (`biacore.rs`): a compound file (`openreadout_core::cfb`) with the run environment (`env`, `run_start`), the sensor chip, the report-point table (`text_table`, `report_unit`), the event log and one storage per cycle, window and curve holding the sensorgram (`read_curve`, `regular_grid`). Every sensorgram is a trace; report points, cycles and events are tables.
- **Seahorse** (`seahorse.rs`): gzip-compressed XML (plate map, injections, executed protocol, every plate reading of the O2 and pH sensors; `parse`, `categories`). Corrected emission per well and reading are traces; plate map, measurements, injections and protocol are tables. OCR/ECAR are Wave's calculations and are not in the file.
- **GenePix** (`gpr.rs`): an ATF 1.0 text file whose header records describe the scan and whose table has one row per microarray feature (`header`, `parse`, `atf_type`).

## Invariants and checks

- ITC: header parsed; injection lines counted against the declared number and the data blocks; full `check` parses every row and flags non-finite values.
- Biacore: compound file parsed; every curve's header and stream size checked; full `check` reads every sample.
- Seahorse: XML parsed; per-well arrays counted against the plate; measurement spans against the protocol; readings checked for non-finite values and the sensors' validity flags.
- GenePix: ATF header and every row parsed; rows counted against the column count. Array lists (`.gal`) and settings (`.gps`) are refused (exit 6).

## Debugging a new file

- `openreadout info FILE --view structure` (Biacore: the compound-file storages); `info --view full --json` → `vendor` (ITC header, Biacore environment and chip, Seahorse XML, GenePix header records).
- `tests/biacore_synthetic.rs` and `tests/seahorse_synthetic.rs` build files; ITC and GenePix have unit tests in their modules (`header_blocks_and_rows`, `parses_a_results_file`).
- Oracles: `oracle/itc_oracle.py`, `oracle/biacore_oracle.py`, `oracle/seahorse_oracle.py`, `oracle/gpr_oracle.py` (compared by the corpus tests in `crates/openreadout-corpus-tests/tests/*_oracle`).

## Fragile spots

- Biacore storage names and curve numbering (`curve_numbers`) were learned from T200 Control Software files; other Biacore generations have no public sample.
- Seahorse timestamps between readings (`seconds_between`) and the plate-map categories depend on the Wave version.
- GenePix values are the text GenePix wrote: no normalization, background correction or flag filtering.
