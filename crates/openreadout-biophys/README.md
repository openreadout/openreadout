# openreadout-biophys

Readers for biophysics bench instruments, such as isothermal titration calorimetry, surface plasmon resonance and Seahorse XF files. This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/formats.html>. Licensed MIT OR Apache-2.0.
