# openreadout-ce

Readers for capillary and chip electrophoresis files: Applied Biosystems ABIF Sanger traces (`.ab1`) and fragment-analysis runs (`.fsa`, `.hid`). This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/formats/abif.html>. Licensed MIT OR Apache-2.0.
