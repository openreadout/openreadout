# openreadout-arrow

Writes the tables, traces and mass spectra of an OpenReadout dataset as Apache Parquet or Arrow IPC, and reads each file back to verify it. This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/reference/commands/export.html>. Licensed MIT OR Apache-2.0.
