# Maintaining `openreadout-dv`

DeltaVision files (`.dv`, `.r3d`; DeltaVision and OMX microscopes, softWoRx), format `deltavision`. Project-wide process: [docs/maintaining.md](../../docs/maintaining.md). Layout: [docs/formats/deltavision.md](../../docs/formats/deltavision.md); provenance: [docs/provenance/deltavision.md](../../docs/provenance/deltavision.md) (hex dumps of corpus files and the documentation of the `mrc` package, BSD-3-Clause; `mrc` and Bio-Formats only as black-box oracles).

## Decode pipeline

1. **Detect** (`header.rs` `looks_like_dv`, `lib.rs` `sniff`): the identifier −16224 at byte 96, which also gives the byte order, and plausible sizes and mode.
2. **Header** (`header.rs` `DvHeader::parse`): the 1024-byte header; the extended header (`section_info`): per section the integers, then the floats, of which the first 14 are named.
3. **Planes** (`dataset.rs` `read_plane`): **section orders branch here** (`DvHeader::section_of`: `ZTW`, `WZT`, `ZWT`); one section is read and swapped to little-endian.

## Invariants and checks

- At open: sizes > 0, a known pixel mode (mode 3 and unknown modes exit 6), sections = wavelengths × Z × time points (exit 4 otherwise), a known section order (exit 6), a non-negative extended-header length.
- `check`: the file length against header + extended header + sections; the extended header large enough for its records.

## Debugging a new file

- `openreadout info FILE --json` → `images[0].extra` has the section order, byte order, mode and the title lines; `info --view full --json` → `vendor.sections[]` the per-section time, stage position, exposure and wavelengths.
- Compare with `mrc` (`oracle/dv_oracle.py`) and Bio-Formats' `showinf -nopix FILE`.
- `tests/synthetic.rs` writes every section order in both byte orders.

## Fragile spots

- The extended header's floats beyond the first 14 are listed, not named; the exposure time's unit (s) and the time stamps (s from the start) are inferred.
- `written_by` comes from softWoRx's title lines (`DECON3D`, `IMGCORR`); a file whose titles were cleared reads as `acquisition`.
- Tiled (multi-panel) acquisitions and the objective names behind the lens ids are not handled.
