# openreadout-medical

Readers for medical and preclinical imaging files: DICOM (single files, series and study folders, DICOMDIR, enhanced multi-frame and whole-slide microscopy), NIfTI-1, NIfTI-2 and Analyze 7.5, and Bruker ParaVision MRI. This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/formats/medical.html>. Licensed MIT OR Apache-2.0.
