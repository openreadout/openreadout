# openreadout-thermo

Reader for Thermo Fisher `.raw` mass-spectrometry files. No vendor library is used. This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/formats/thermo-raw.html>. Licensed MIT OR Apache-2.0.
