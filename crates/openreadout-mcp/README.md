# openreadout-mcp

MCP (Model Context Protocol) server that exposes OpenReadout operations as agent tools. This crate is part of [OpenReadout](https://github.com/openreadout/openreadout), which reads raw lab-instrument files without vendor software, prints JSON, exports to open formats and runs as an MCP server. Documentation: <https://openreadout.github.io/openreadout/reference/mcp.html>. Licensed MIT OR Apache-2.0.
