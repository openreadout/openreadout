OpenReadout in the browser

Drop an instrument file to see what is in it: Zeiss CZI, Nikon ND2, Leica LIF, OME-TIFF, FCS, Thermo RAW, mzML, Axon ABF, NWB and the other formats OpenReadout reads.

Nothing is uploaded. The file is read by WebAssembly in this tab; the page's security policy forbids it from making any network request.
